# Frame Cost｜AI 影片成本比較

先算成本，再按生成。這是一個繁體中文、本機優先的 AI 影片預算試算器。它不需要帳號、API 金鑰或第三方執行套件，不會呼叫生成模型、購買點數或產生帳單。

## 啟動

從專案目錄執行 `python3 -m http.server 8040 --bind 127.0.0.1`，打開 <http://localhost:8040>。不必安裝 npm 套件。使用支援 ES modules 與 BigInt 的現代瀏覽器。也可以將專案部署在靜態網站伺服器。

測試使用 Node.js 22：`node --test`。GitHub Actions 在 push 和 pull request 時執行語法檢查與測試。

## 做一份預算

1. 設定每鏡成片秒數、每次生成的完整片長、同規格鏡頭數、每鏡**包含第一次**的付費嘗試次數，以及聲音與畫質。相異規格用不同鏡組。每鏡採用一次生成結果再裁短，不拼接、不自動補足片長。
2. 比較通過**全部**鏡組條件的單一費率列。不會自動混搭不同費率／端點、不換匯、不把任意片長進位成可生成片長。使用每秒、每次生成，或點數費率（每秒／每次耗點 × 每點單價）。只計生成成本，不含稅、訂閱、折扣、最低儲值、額外服務或後製。
3. 展開「價表與來源」的任一列，調整規格、費率或核對時間；更動後會標記為自訂。在「新增費率」輸入自己的合約價。價格只是估算，請自行核實。超過 30 天未核對會提醒，沒有可驗證來源的數字不是官方報價。
4. 匯出文字或 UTF-8 CSV 製作預算。資料只留在目前瀏覽器的 localStorage；「重設資料」須確認才會還原預設。未上傳任何素材，官網來源連結僅在自行點選時開啟。

## 資料邊界

2026-11-18 UTC 核對以下公開的文字轉影片端點，費率均為美元；供應商未公布這些價格的起始日。只估標準 16:9／9:16 影片，不含額外服務。

| 供應商與模型 | 本機收錄的規格 | 無音訊 | 含音訊 |
| --- | --- | --- | --- |
| fal · Veo 3.1 Fast | 720p：4／6／8 秒；1080p：8 秒 | USD 0.10／秒 | USD 0.15／秒 |
| fal · Veo 3.1 Fast | 4K：8 秒 | USD 0.30／秒 | USD 0.35／秒 |
| Runway Dev · Veo 3.1 Fast | 720p：4／6／8 秒；1080p：8 秒 | 10 點／秒 | 15 點／秒 |

- **fal：**[定價頁](https://fal.ai/models/fal-ai/veo3.1/fast)、[精確端點規格](https://fal.ai/models/fal-ai/veo3.1/fast/api#schema)、[美元計價條款](https://fal.ai/legal/terms-of-service)。官方介紹舉了 5 秒的價格例子，但端點輸入枚舉只有 4、6、8 秒，因此不接受 5 秒。不同欄位分別列出不等於所有組合皆可用；依 [Veo 模型對高解析度的限制](https://aistudio.google.com/docs/veo#veo-model-parameters)，1080p、4K 僅收錄保守的 8 秒組合。依 [fal 計費說明](https://fal.ai/docs/documentation/model-apis/pricing)，試算的「付費嘗試」包含已生成但被剪掉的版本，不把排隊或平台伺服器錯誤算作成功輸出。
- **Runway Dev（非消費者訂閱）：**[官方文字轉影片規格及跨欄位限制](https://dev.runwayml.com/learn/veo-3-1-api)和[開發者點數價表](https://docs.dev.runwayml.com/guides/pricing/)對應到同一模型 `veo3.1_fast`。每個 API 點數 USD 0.01；同為 8 秒、3 次付費嘗試，24 秒輸出需要 240 點（無音訊）或 360 點（含音訊）。與 fal 的 720p／1080p 估算相同：USD 2.40 或 USD 3.60。fal 的 4K 同例為 USD 7.20 或 USD 8.40；Runway 此端點未收錄 4K。
- **示範：**額外兩列逐次與點數方案是虛構例子，不是供應商報價。Replicate、Google Cloud 與 Gemini 不列入，未獨立核實的價表、計價單位或已退役端點不會進入有效比較。

## 結構

- `index.html`、`style.css`：響應式介面；主視覺是內建原創 SVG，不下載外部素材或字體。
- `app.mjs`：表單、本機儲存、比較與下載。
- `core.mjs`：費率快照、規格驗證、精確十進位試算、匯出與儲存格式。
- `tests/`：使用內建 Node test runner 的固定測例。
